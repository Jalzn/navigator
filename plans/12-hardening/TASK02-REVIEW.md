# Task02 independent-review protocol

Status: awaiting review of a fresh current-source publication.

An independent reviewer must recompute the evidence index and every indexed
output, confirm the source inventory digest against the current tree, inspect
all exact matrix identities and structured results, and verify the literal
macOS/aarch64 scope. A GO is valid only as a sidecar attestation stored with the
reviewed evidence directory. The release gate requires that sidecar explicitly;
this narrative document cannot authorize a release.

Historical GO reviews remain valid only for the immutable source snapshots and
evidence directories they name.
